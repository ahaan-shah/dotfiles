# NVIDIA — NOT INSTALLED BY THIS SCRIPT. Nothing reads this file.
#
# It is kept as a record of what this particular laptop uses, because getting
# hybrid graphics wrong costs a black screen and a TTY recovery rather than an
# error message. Read the "Hybrid graphics" section of the top-level CLAUDE.md
# before installing any of it. Three points that are easy to get wrong:
#
#  1. AQ_DRM_DEVICES is a COLON-SEPARATED list. A PCI by-path name contains
#     colons, so passing one shreds it into fragments, aquamarine finds no GPU
#     and Hyprland aborts at startup. Pass a plain /dev/dri/cardN.
#  2. Card numbering is probe-order dependent and DOES change when a driver is
#     installed — never hardcode cardN. hyprland.lua resolves it from the PCI
#     address at parse time for exactly this reason.
#  3. Do NOT enable nvidia-suspend / nvidia-resume / nvidia-hibernate. They run
#     nvidia-sleep.sh, which does `chvt 63` before every suspend — pointed at an
#     ext_session_lock_v1 lockscreen that risks an unrecoverable locked session.
#     VRAM survives a full power-off without them.
#
# Prebuilt, not -dkms: one stock kernel here, and a prebuilt module has no
# compile step that can fail mid-upgrade and leave the machine without one.
# The cost is that `linux` and `nvidia-open` must always move together —
# never partial-upgrade.
nvidia-open
nvidia-utils
nvidia-prime
