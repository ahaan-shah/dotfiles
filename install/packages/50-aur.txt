# AUR, built with yay (which the installer bootstraps), one at a time so a
# package that fails to build costs that package and not the rest. Failures are
# listed at the end of the run and in verify.

# them voxtype's bind does nothing, the cursor is the fallback theme, mimeapps.list is
# repointed from Zen at chromium, and the dock drops pins for what is absent. The AUR packages
# that ARE required never come through this file: python-pywal (10-core.txt),
# asusctl (install_power_backend) and limine-snapper-sync (the snapshots phase).
# 55-aur-heavy.txt stays behind its own flag.
#

# manifest in this directory.
