#
# These used to sit behind a per-group y/n prompt. That prompt is gone: the
# point of this installer is to reproduce the desktop, and answering "n" to a
# group produced a machine that was subtly not this one. Anything genuinely
# unwanted is one `pacman -R` away afterwards.
#
# Deliberately NOT here (the user's call, and each is a large install nobody
# should get by surprise): r, steam, discord.
